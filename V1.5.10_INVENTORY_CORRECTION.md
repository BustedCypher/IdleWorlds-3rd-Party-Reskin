# v1.5.10 — Inventory ItemRow correction

This release is a narrow correction to v1.5.9 based on the first live Inventory screenshot.

## Confirmed live issues corrected

- **Blank item artwork:** the new inventory icon was marked `role="button"`. The shared button skin applies a `background-image: ... !important`, which overrode AtlasService's sprite background. Inventory icons are now neutral focusable tooltip surfaces, so the atlas owns their background image again.
- **Ancient's Vestment duplicate/overflow text:** native React parent wrappers concatenate the entire row into `textContent`. v1.5.9 treated some of those parent aggregates as owned-item detail lines. The extractor now removes nested wrapper duplicates and prefers atomic child lines while retaining genuinely repeated sibling lines (for example two identical socketed gems).
- **Duplicate Set Bonus line:** decorative glyphs such as `✦`, `📁`, and `💎` are stripped before semantic classification. `✦ set bonus` is therefore recognised as native action text and is not repeated as an item detail when the real Set Bonus button is already preserved.
- **Action-rail collision:** dynamic detail/body rails now have hard overflow containment and ellipsis as a final safety net, so malformed native text cannot render under Equip/List/Lock controls.
- **Repeated gem compression:** two real sibling lines with the same socket effect are no longer collapsed during DOM extraction; InventoryModel can correctly render the effect once with `×2`.

No HUD, Skills, tooltip-lifecycle, ItemDatabase, or AtlasService behavior was otherwise redesigned in this release.
