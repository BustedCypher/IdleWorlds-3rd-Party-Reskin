# CSS structure contract

> Generated by `handoff/native-render-migration/tools/css-structure-contract.mjs` from `src/styles/*.css`. Do not edit; regenerate.

Every relationship below is one the shipped theme CSS **requires** of the DOM. They are not layout suggestions: each is a selector that stops matching, silently, when the relationship is broken. A descendant selector (`A B`) survives an extra wrapper; none of these do.

- **child** `A > B`: B must be a DIRECT child of A. Adding a wrapper between them breaks it.
- **adjacent sibling** `A + B`: B must IMMEDIATELY follow A under the same parent.
- **later sibling** `A ~ B`: B must follow A under the same parent (anything may sit between).
- **has** `A:has(> B)`: A must have B as a direct child (or `+`/`~` sibling).
- **positional** `:first-child`, `:nth-child()`, `:last-of-type`, …: the element's index among its siblings matters. A node the skin appends counts as a sibling too.
