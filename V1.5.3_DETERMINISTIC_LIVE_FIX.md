# v1.5.3 — Deterministic live-DOM correction

This pass replaces two brittle heuristics that survived v1.5.2.

## Player name

- Header-name discovery now includes clickable `button`, `a`, and `role=button` controls.
- It uses the identity block's DOM line order (brand → player → title → combat/zone → online) before visual font-size scoring.
- The detected name branch has cosmetic gradient/text-fill/background effects neutralised while preserving the original element and click handler.
- The entire HUD identity block has a readable foreground fallback, with explicit role overrides for brand/title/location/online.

## Skill XP readout

- Exact same-text ancestry is no longer required.
- The renderer positively identifies the level/progress readout and walks upward through its safe visual-only branch.
- Intermediate wrappers are flattened until another semantic skill datum/control is encountered.
- Readout pseudo-elements are disabled in case the native card frame is drawn with `::before`/`::after`.

No additional MutationObserver is introduced and no React-owned gameplay node is reparented.
