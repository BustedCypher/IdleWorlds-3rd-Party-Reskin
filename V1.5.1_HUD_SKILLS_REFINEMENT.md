# IdleWorlds Fantasy Skin v1.5.1 — HUD & Skills Refinement

This pass makes the v1.5.0 HUD/navigation and Skill Actions interface the visual reference standard before the ItemRow/Inventory work begins.

## HUD
- Explicitly identifies and restyles the live player-name node so native dark text classes cannot make it unreadable.
- Detects identity, utility and status zones without reparenting React nodes.
- Uses a compact three-zone layout only when those zones are positively identified as distinct direct children.
- Converts six boxed status cards into a compact information rail where the live structure permits it.
- Flattens the oversized native navigation shell while retaining a joined forged-metal tab track.
- Classifies Zone controls and reduces their command-button footprint.
- Keeps utility buttons as compact icon controls instead of independent dashboard cards.

## Skill Actions
- Removes the large low-opacity skill watermark glyphs.
- Flattens the level/progress readout so XP data no longer resembles a callout button/card.
- Reduces panel padding, spacing and command widths to increase information density.
- Strengthens the action-title hierarchy.
- Improves disabled action contrast so unavailable actions remain legible.
- Keeps the verified three-zone layout and all v1.4.1 lifecycle protections.

## Safety rules retained
- One MutationObserver only.
- No React-owned gameplay node reparenting.
- Unknown compact panels receive no skill chrome.
- Existing gameplay buttons remain the real buttons.
- Runtime atlases stay pinned to the immutable repository revision.
